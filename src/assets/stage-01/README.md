# Stage 1 Generated Asset Pack

Generated for the Level 1 Thai practice-adventure upgrade.

## Transparent PNG Sheets

- `stage-01-rift-glyph-vfx.png` - 4x3 rift glyph and Thai magic effects.
- `stage-01-pronunciation-hit-vfx.png` - 4x3 pronunciation pass, retry, heal, combo, and pulse effects.
- `stage-01-lobby-practice-props.png` - 4x3 interactive lobby props for phrase prompts.
- `stage-01-su-cutins.png` - 3x2 Su reaction cut-ins for coaching moments.
- `stage-01-clear-card.png` - stage-clear reward card art with empty areas for UI text.
- `stage-01-prop-*.png` - cropped prop sprites extracted from the lobby props sheet for direct UI use.

## Chroma Source Files

The matching `*-source.png` files are the original generated chroma-key sheets.
They are kept so the alpha extraction can be rerun or adjusted later.
