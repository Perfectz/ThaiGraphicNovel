# Su Stage Reaction Variants

Transparent PNG cutouts derived from the existing Su reaction sprites for Stage 1 pronunciation feedback.

- `su-stage-listening.png` - active listening / review mode
- `su-stage-great.png` - strong pass feedback
- `su-stage-excellent.png` - near-perfect feedback and stage clear
- `su-stage-try-harder.png` - close but needs correction
- `su-stage-failure.png` - missed phrase or skipped phrase
