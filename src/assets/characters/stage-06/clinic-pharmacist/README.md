# Clinic Pharmacist Reaction Sprites

Visual novel reaction sprites for chapter 6, `clinic-and-pharmacy`.

The `clinic-pharmacist-reactions-sheet-source.png` file is the single green-screen source sheet used to preserve character consistency across the six expressions. `clinic-pharmacist-reactions-sheet.png` is the full transparent version, and the individual PNG files are the cropped transparent sprites used by the game.

Reactions:

- `smile`
- `explaining`
- `surprised`
- `worried`
- `determined`
- `playful`
